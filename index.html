Instalação do npm

Para permitir a execução de scripts no PowerShell do VS Code:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Verificando versões

Mostra a versão do Node.js instalada:

node -v

Mostra a versão do npm instalada:

npm -v

Criando projetos

Cria um projeto npm com perguntas interativas:

npm init

Cria o projeto usando configuração padrão:

npm init -y

Gerenciamento de pacotes

  • Instala dependências do projeto:
    npm install
  • Instala um pacote:
    npm install pacote
  • Instala um pacote como dependência de desenvolvimento:
    npm install -D pacote
  • Remove um pacote:
    npm uninstall pacote
  • Lista os pacotes instalados:
    npm list
  • Mostra os scripts disponíveis do projeto:
    npm run
  • Executa um pacote temporário sem instalação global:
    npx

Scripts do projeto

  • Executa o script de inicialização, se definido no package.json:
    npm start
  • Executa o script de desenvolvimento, se definido no package.json:
    npm run dev
  • Executa os testes definidos no projeto:
    npm test
  • Gera a versão de produção, se houver esse script:
    npm run build

Instalação e atualização

  • Instala exatamente as versões do package-lock.json:
    npm ci
    Requer um arquivo package-lock.json ou npm-shrinkwrap.json.
  • Atualiza dependências dentro das versões permitidas no package.json:
    npm update
  • Mostra dependências com versões mais recentes disponíveis:
    npm outdated
  • Lista apenas as dependências diretas do projeto:
    npm list --depth=0

Auditoria e manutenção

  • Verifica vulnerabilidades conhecidas nas dependências:
    npm audit
  • Tenta corrigir vulnerabilidades sem mudanças incompatíveis:
    npm audit fix
    Pode atualizar o package-lock.json. Revise as alterações antes de enviar o projeto.
  • Verifica a integridade do cache local do npm:
    npm cache verify

Comandos Git

Execute os comandos no terminal, dentro da pasta do projeto. Troque os valores de exemplo pelos seus dados.

  • Confere se o Git está instalado:
    git --version
  • Configura seu nome para os commits:
    git config --global user.name "Seu Nome"
  • Configura seu e-mail para os commits:
    git config --global user.email "voce@exemplo.com"
  • Inicia um repositório Git na pasta atual:
    git init
  • Baixa uma cópia de um repositório remoto:
    git clone URL_DO_REPOSITORIO
    Substitua pelo endereço HTTPS ou SSH do repositório.
  • Mostra arquivos modificados e o estado do repositório:
    git status
  • Prepara um arquivo para o próximo commit:
    git add nome-do-arquivo
  • Prepara todas as alterações da pasta:
    git add .
  • Registra as alterações preparadas:
    git commit -m "Descreva a alteracao"
  • Exibe o histórico resumido de commits:
    git log --oneline
  • Mostra alterações ainda não preparadas para commit:
    git diff
  • Mostra alterações já preparadas para commit:
    git diff --staged
  • Lista as branches locais:
    git branch
  • Cria uma branch e muda para ela:
    git switch -c nome-da-branch
  • Muda para uma branch existente:
    git switch nome-da-branch
  • Lista os repositórios remotos configurados:
    git remote -v
  • Conecta o projeto a um repositório remoto:
    git remote add origin URL_DO_REPOSITORIO
    Use quando o projeto ainda não tem um remoto chamado origin.
  • Envia a branch atual e configura o upstream:
    git push -u origin main
    Troque main pelo nome da sua branch, se necessário.
  • Envia novos commits para o remoto:
    git push
  • Baixa e integra alterações da branch remota:
    git pull origin main
    Confirme o nome da branch antes de executar.
  • Baixa informações do remoto sem integrar alterações:
    git fetch
  • Guarda temporariamente alterações ainda não commitadas:
    git stash
  • Restaura as alterações guardadas mais recentemente:
    git stash pop
  • Descarta alterações locais de um arquivo:
    git restore nome-do-arquivo
    Atenção: remove as alterações locais não commitadas desse arquivo.

Tags HTML: descrições e exemplos

  • <a>: link para outra página, arquivo ou seção.
    <a href="https://exemplo.com">Visitar site</a>
  • <article>: conteúdo independente, como uma notícia ou publicação.
    <article><h2>Notícia</h2><p>Texto</p></article>
  • <aside>: conteúdo complementar ao conteúdo principal.
    <aside>Leia também</aside>
  • <body>: corpo da página, onde fica o conteúdo visível.
    <body><main>Conteúdo</main></body>
  • <button>: botão que pode ser acionado pelo usuário.
    <button type="button">Salvar</button>
  • <code>: trecho de código.
    <code>npm test</code>
  • <div>: contêiner genérico para agrupar conteúdo.
    <div class="grupo">Conteúdo</div>
  • <footer>: rodapé de uma página ou seção.
    <footer>Fim da página</footer>
  • <form>: formulário para envio de informações.
    <form action="/enviar" method="post">Campos</form>
  • <h1>: título principal de uma seção.
    <h1>Título principal</h1>
  • <h2>: título de segundo nível.
    <h2>Uma seção</h2>
  • <h3>: título de terceiro nível.
    <h3>Um tópico</h3>
  • <head>: metadados e configurações do documento HTML.
    <head><title>Minha página</title></head>
  • <header>: cabeçalho de uma página ou seção.
    <header><h1>Meu site</h1></header>
  • <html>: elemento raiz de um documento HTML.
    <html lang="pt-BR"><body><main>Conteúdo do documento</main></body></html>
  • <img>: imagem incorporada ao documento.
    <img src="foto.jpg" alt="Descrição da foto">
  • <input>: campo de entrada de dados.
    <input type="email" placeholder="Seu e-mail">
  • <label>: rótulo associado a um campo de formulário.
    <label for="email">E-mail</label>
  • <li>: item de uma lista.
    <li>Item da lista</li>
  • <link>: referência a um recurso externo, geralmente uma folha de estilos.
    <link rel="stylesheet" href="estilos.css">
  • <main>: conteúdo principal do documento.
    <main>Conteúdo principal</main>
  • <nav>: grupo de links de navegação.
    <nav><a href="/">Início</a></nav>
  • <ol>: lista ordenada.
    <ol><li>Primeiro passo</li></ol>
  • <option>: opção disponível em uma lista de seleção.
    <option value="br">Brasil</option>
  • <p>: parágrafo de texto.
    <p>Um parágrafo.</p>
  • <script>: código JavaScript ou referência a um arquivo de script.
    <script src="app.js"></script>
  • <section>: seção temática do documento.
    <section><h2>Sobre</h2><p>Texto</p></section>
  • <select>: lista de opções selecionáveis.
    <select><option>Brasil</option></select>
  • <small>: texto complementar ou apresentado em tamanho menor.
    <small>Observação</small>
  • <span>: contêiner genérico em linha.
    <span class="destaque">Texto</span>
  • <strong>: texto de grande importância, normalmente exibido em negrito.
    <strong>Importante</strong>
  • <style>: regras CSS incorporadas ao documento.
    <style>p { color: blue; }</style>
  • <table>: tabela de dados.
    <table><tr><th>Nome</th></tr></table>
  • <td>: célula de dados de uma tabela.
    <td>Ana</td>
  • <textarea>: campo de texto com várias linhas.
    <textarea name="mensagem"></textarea>
  • <th>: célula de cabeçalho de uma tabela.
    <th scope="col">Nome</th>
  • <title>: título do documento exibido na aba do navegador.
    <title>Minha página</title>
  • <tr>: linha de uma tabela.
    <tr><td>Ana</td></tr>
  • <ul>: lista não ordenada.
    <ul><li>Item</li></ul>
